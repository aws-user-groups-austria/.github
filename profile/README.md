### Get involved

- **Speak at a meetup:** a 25 to 35 minute technical talk, submitted on [Sessionize](https://sessionize.com/aws-community-austria).
- **Host or sponsor a meetup:** a room, food and drinks for one evening. The [prep guide](https://awscommunity.at/prep-guide/) shows who does what and when.
- **Every meetup** has its own page with the agenda, the talks, the speakers and the slides: [all meetups](https://awscommunity.at/meetups/).

### What's in here

| Repository | What |
|---|---|
| [aws-community-austria-website](https://github.com/aws-user-groups-austria/aws-community-austria-website) | [awscommunity.at](https://awscommunity.at): the groups, a page per meetup, the prep guide, the room screen at `/present/` |
| [meetup-workspace](https://github.com/aws-user-groups-austria/meetup-workspace) | Start here for the meetup tools: one `make` runs a whole meetup evening from just its Meetup link |
| [meetup-sync](https://github.com/aws-user-groups-austria/meetup-sync) | A Meetup event page to `event.json`, with Sessionize, photos and logos |
| [meetup-event-vienna](https://github.com/aws-user-groups-austria/meetup-event-vienna) | One folder per meetup, and the shared photos, logos and badges |
| [meetup-stream-templates](https://github.com/aws-user-groups-austria/meetup-stream-templates) | The room screen: Remotion scenes and the web player, also the live header on each meetup page |
| [meetup-deck](https://github.com/aws-user-groups-austria/meetup-deck) | The group's slide deck, filled in for a meetup, as .pptx and PDF |

Built by and for the community. The tools are free to reuse for your own user group; see also the
[AWS User Group Toolkit](https://github.com/aws-user-group-toolkit).

<sub>AWS User Groups are run by volunteers and are not affiliated with Amazon Web Services.</sub>
